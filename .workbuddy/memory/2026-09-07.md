# 2026-09-07

## 从零创建 iTab 启动台起始页浏览器扩展（MV3）

需求：浏览器插件作为起始页，外观类似 macOS Launchpad，可添加网页收藏，自动获取 favicon 或自定义图标。

### 技术选型
- 纯原生 HTML/CSS/JS + Chrome MV3，**零构建步骤**（可直接「加载已解压的扩展程序」）
- 无第三方依赖；图标 PNG 由 `tools/make_icons.py` 手写 zlib/PNG 编码器生成（环境无 PIL）
- 数据层 `chrome.storage.local`，无扩展环境时降级 `localStorage`（便于本地 HTTP 预览与自动化截图）
- 覆盖入口：`chrome_url_overrides.newtab = newtab.html`
- 权限极小化：只 `storage` + `activeTab`；`bookmarks` 作为 `optional_permissions` 按需申请

### 文件职责
- `js/store.js` — 数据层 + 默认站点 + 设置默认值（含 localStorage 降级）
- `js/favicon.js` — favicon 多源回退（`{domain}/favicon.ico` → DuckDuckGo → Google s2），失败降级「首字母 + hash 渐变色」；emoji/letter/上传转 dataURL
- `js/launchpad.js` — 网格渲染、分页（每页固定留最后一个槽做 `+`）、HTML5 拖拽重排（边缘悬停 0.5s 自动翻页）、搜索过滤、编辑模式抖动
- `js/app.js` — 添加/编辑弹窗、设置面板、7 套 CSS 渐变壁纸、导入导出 JSON、书签导入
- `newtab.html?bg=&blur=&dim=&edit=1&demo=1&settings=1` — 仅预览环境生效的调试入口（Chrome 的 newtab 无 query string）

### 踩过的坑
1. **`.btn[hidden]` 失效**：自定义 `.btn{display:inline-flex}` 特异性高于 user-agent 的 `[hidden]{display:none}`，删除按钮在「添加」弹窗里照样显示。需显式写 `.btn[hidden]{display:none}`。
2. **分页满页时漏掉 `+` 槽**：最初只在 `arr.length < pageSize` 时补 add-slot，item 正好填满一页就没有添加入口。改为每页固定 `pageSize-1` 个 item + 1 个 add-slot，空位用 `null` 占位补齐网格。
3. **浅色壁纸（sakura/bigsur）上白色标签不可读**：`body[data-bg="sakura"]` 加 `.bg-tint` 暗化 34% + 标签加深阴影。
4. **图标生成脚本路径**：`OUT_DIR` 用 `dirname(dirname(__file__))`，否则图标落到 `tools/img/`。

### 验证方式
`python3 -m http.server 8090` + Chrome headless 截图（`-–headless=new --screenshot --virtual-time-budget=5000`），确认 7 套壁纸、添加弹窗、设置面板、编辑模式均正常，favicon 自动抓取全部成功。截图存于 `img/previews/`。

## 搜索框增加清除图标
- `newtab.html`：`.topbar-center` 内 `#searchInput` 之后加 `<button class="search-clear" id="btnSearchClear">`（内联 SVG 叉号，默认 `hidden`）
- `css/launchpad.css`：新增 `.search-clear` 样式（18px 圆形半透明白底）；注意 `.search-clear[hidden]{display:none}` 必须显式写（同 `.btn[hidden]` 坑，`display:flex` 会压过 UA 样式）。`.topbar-center` 右 padding 由 16px 收窄到 10px 给按钮让位
- `js/launchpad.js`：在 `#searchInput` 绑定处加 `syncClear()`（按 value 长度切 hidden）/ `clearSearch()`（清空 + `_applyFilter("")` + refocus）；`input` 事件里同步显隐；按钮 click 阻止冒泡后清空；输入框内按 `Escape` 也清空（全局 keydown 处理器会 ignore INPUT，所以不冲突）
